# AI Ping (WaitB) · 模型首字测速台

一款基于 **Rust（Tauri 2）+ 原生 Web 前端** 打造的极简、极速、高精度的 LLM / API 接口首字时延（TTFT）测速与诊断工具。

> 🦀 **安全声明**：本项目使用 **Rust** 语言编写，所有 API Key **仅保存在本地**，不上传任何第三方服务器。联网功能仅用于**同步时间、测试网络延迟、测试模型首字**这三件事，**无任何泄露风险**，代码**完全透明开源**。你也可以克隆仓库后用 Tauri 自行构建安装包，丰俭由人～

---

## ✨ 功能特性

### ⚡ 精准首字测速（TTFT）
- 提供精准的首字时延测量，从请求发起到第一个可见 Token 返回全链路计时；
- 拥有**完善的自动重连**机制，可自定义重连次数，测速中途可**快速结束任务**；
- 尽最大可能提供足够高的测试**可靠性与精度**，尽可能降低网络抖动带来的干扰。

### 🚀 极速配置模型
- 只需要填入 **API URL + 模型名称**，立刻开始测速，零学习成本；
- 支持**单独测速**与**一键全部测速**，方便快捷又可靠。

### 🪙 超低 Token 消耗
- 输入仅消耗约 **3 tokens**，输出约 **24 tokens**，刷榜测速不心疼钱包。

### 🕐 时间诊断
- 同时展示**网络时间**与**本地时间**，并支持**一键同步时间**；
- 快速分析本地时钟是否存在偏移问题，排查签名 / 鉴权类故障的好帮手。

### 📡 网络测速
- 内置网络延迟测速功能，先排除网络问题再看模型问题，分析链路一目了然。

### 🎨 精美轻量
- 精美的页面与流畅动画，小巧不占内存与性能；
- **便携版（exe）无需安装**，双击即用，随身带走。

## 🛠️ 构建与运行

### 环境准备
- [Node.js](https://nodejs.org/) (v18+)
- [Rust](https://www.rust-lang.org/) (v1.77+)

### 本地开发
```bash
npm install
npm run tauri dev
```

### 生产打包
```bash
npm run build -- --bundles nsis,msi
```
